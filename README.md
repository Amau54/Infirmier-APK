# Tournée Infirmier — APK Android

Ce dépôt distribue uniquement l’application Android compilée et son manifeste de mise à jour. Le code source applicatif reste privé.

[**Télécharger la dernière APK**](https://github.com/Amau54/Infirmier-APK/releases/download/android-latest/infirmier.apk)

Installer cette version une première fois. Les suivantes seront proposées automatiquement dans l’application, avec confirmation Android. La signature et l’intégrité de l’APK sont vérifiées avant installation. Ne désinstallez pas l’application pour effectuer une mise à jour.
